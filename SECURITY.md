# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately. Don't open a public issue, pull request, or discussion.

1. Go to the **Security** tab of the affected repository.
2. Click **Report a vulnerability** (GitHub private vulnerability reporting).
3. Describe the issue, the affected version or commit, and steps to reproduce.
